# Hostel Management System

## Project Information
- **Project Name:** Hostel Management System
- **Enrollment Number:** IU2541230016
- **Course:** B.Tech CSE

- **Language:** C++

## Project Description
The Hostel Management System is a console-based C++ application designed to manage student records, hostel rooms, and room allocations. It demonstrates Object-Oriented Programming concepts and file handling.

## Key Features
- Add and display student and room records
- Search, update, and delete student records
- Allocate and vacate hostel rooms
- Generate hostel reports
- Save and load records using text files

## OOP Concepts Used
- Classes and Objects
- Encapsulation
- Inheritance
- Runtime Polymorphism
- Constructors and Destructors
- Dynamic Memory Allocation
- File Handling
- Exception Handling (where implemented)

## Files Included
- `main.cpp` — Main C++ source code
- `HostelManagementSystem.exe` — Compiled application
- `students.txt` — Student records
- `rooms.txt` — Room records
- `allocations.txt` — Room allocation records

## Compilation
Compile the program using GCC/G++:

```bash
g++ main.cpp -o HostelManagementSystem.exe
```

Run the executable on Windows:

```bash
.\HostelManagementSystem.exe
```

## Project Purpose
This project was developed as part of the CPP12 academic assignment to demonstrate C++ programming and Object-Oriented Programming concepts.
